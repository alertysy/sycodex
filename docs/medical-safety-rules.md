# 医学安全规则（MVP）

## 1. 红旗规则 `medical_red_flags`
首期需可配置化（JSON/YAML/DB 均可），至少包含：
- 胸痛/胸闷 + 大汗/呼吸困难
- 意识障碍/抽搐/一侧肢体无力
- 明显出血/呕血/黑便
- 高热持续 + 精神差/明显脱水
- 极端血压伴症状
- 术后突发恶化
- 儿童特殊高危
- 孕产妇特殊高危
- 明显药物不良反应/过敏反应
- 自伤/自杀风险

命中处理：
- 立即中断普通链路
- 状态转移到 `doctor_handoff`
- 记录审计事件 `red_flag_hit`
- 禁止商业表达

## 2. 冲突规则 `conflict_detection`
至少识别：
- 主诉 vs 历史病史冲突
- 结构化答案 vs 自由文本冲突
- 检查结果 vs 当前建议冲突
- 用药信息冲突
- 既往禁忌 vs 当前建议冲突

命中处理：
- 阻断直接进入服务承接
- 要求澄清或人工复核
- 记录审计事件 `conflict_blocked`

## 3. 第四级预防 `overmedicalization_risk`
首版可规则占位，但必须有可执行逻辑：
- 重复检查
- 过密复查
- 多重用药风险
- 干预阈值不清
- 低价值筛查
- 观察等待更合适但被推向高成本方案

命中处理：
- 标记 `followup_level = 4`
- 输出“观察等待/低成本替代”建议
- 默认阻断高成本服务推荐（除非人工放行）

## 4. 安全优先级
`SafetyAgent` > `ServiceOrchestrationAgent` > `ValueConversionAgent`

## 5. 审计要求
关键安全节点必须写入 `audit_memory`：
- 红旗命中
- 冲突命中
- 状态机强制跳转
- 商业表达拦截
- 医生/人工接管触发
