# medical-system skill

## 目的
在 AI 医疗产品操作系统仓库内，确保以下变更遵循一致治理：
1. 红旗规则维护
2. 状态机变更
3. 接口契约变更
4. 审计要求变更

## 使用时机
当任务涉及以下任一内容时启用本技能：
- 医学安全规则新增/调整
- 业务状态新增/删除/转移约束变更
- 外部接口 schema、错误码、超时重试策略变更
- 审计事件字段、留痕范围、合规要求变更

## 标准流程
1. 识别变更类别（规则/状态机/契约/审计）。
2. 同步更新对应文档：
   - `docs/medical-safety-rules.md`
   - `docs/state-machine.md`（如存在）
   - `docs/api-contracts.md`
   - `docs/architecture.md`（如涉及系统边界）
3. 更新类型定义与实现边界（contracts/mocks/adapters）。
4. 为关键路径补充测试（至少单测+状态机测试）。
5. 确认审计事件完整性（含 traceId / stateFrom / stateTo / decisionPayload）。

## 变更检查清单
- [ ] 是否引入高危漏接管风险
- [ ] 是否破坏状态机强约束
- [ ] 是否导致商业表达前置或越权
- [ ] 是否补齐 mock 与 contract 同步
- [ ] 是否补齐关键审计事件

## 输出要求
每次变更说明必须包含：
- 改动目的
- 安全影响
- 状态机影响
- 接口兼容性影响
- 需要人工补齐的未知项
